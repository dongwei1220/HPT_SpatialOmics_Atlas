# HPT_SpatialOmics_Atlas
This repository includes the codes for the preprocessing, integration, and visualization of single-cell and spatial multi-omics data from the monkey HPT atlas.

To be compatible with updated versions, the code has also been tested in R (version 4.3.3), with the following required packages: Seurat (version 4.4.0); SeuratObject (version 4.1.4); harmony (version 1.2.0); ArchR (version 1.0.2); ggplot2 (version 4.0.1); dplyr (version 1.1.3); tidyverse (version 2.0.0); reshape2 (version 1.4.4), et al.
